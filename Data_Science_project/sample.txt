Spark is a fast framework for processing large amounts of data.
It distributes data across multiple computers to speed up calculations.
PySpark allows developers to write Spark programs using Python code.
DataFrames store structured data in rows and columns like a table.
Transformation operations like filter and select modify data without changing it directly.
Actions like count and show trigger the actual execution of tasks.
Resilient Distributed Datasets are the underlying core data structure in Spark.
Spark SQL lets users query data using standard SQL commands easily.
Lazy evaluation means Spark delays processing until an action is called.
Running PySpark in Jupyter Notebook simplifies interactive testing and analysis.
